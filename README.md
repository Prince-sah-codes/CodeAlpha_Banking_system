# 🏦 Banking System

A simple **console-based Banking System** developed in **C++** as part of my internship project.

The project demonstrates basic banking operations such as creating an account, depositing money, withdrawing money, checking balance, and viewing account details.

## 📌 Project Overview

This Banking System is designed as a beginner-friendly C++ project to understand how basic banking operations can be implemented using programming concepts.

The project runs directly in the terminal/console and uses a simple menu-driven approach.

## ✨ Features

* Create a new bank account
* View account details
* Deposit money
* Withdraw money
* Check account balance
* Basic input validation
* Simple and easy-to-use menu
* Console-based interface

## 🛠️ Technologies Used

* **C++**
* Object-Oriented Programming concepts
* Standard C++ libraries
* VS Code / any C++ compiler

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Prince-sah-codes/CodeAlpha_CGPA-calculator.git
```

### 2. Open the project

Open the project folder in **VS Code** or any C++ IDE.

### 3. Compile the program

Using g++:

```bash
g++ banking_system.cpp -o banking_system
```

### 4. Run the program

On Windows:

```bash
banking_system.exe
```

Or simply run the `.cpp` file using the Run/Build option in VS Code.

## 💡 How It Works

When the program starts, a menu is displayed to the user.

The user can select different options such as:

```text
1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Balance
5. Display Account Details
6. Exit
```

Based on the selected option, the program performs the required banking operation.
